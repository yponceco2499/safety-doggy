## Ce qui reste hors de portée de ces documents

- **Publier réellement** les CGU et la politique de confidentialité à une URL publique — aucun hébergement disponible dans ce projet (budget récurrent zéro). Options : une page GitHub Pages du dépôt, ou publier ces deux fichiers en Markdown via un Artifact partagé.
- **Captures d'écran et vidéo** — nécessitent un appareil réel, non générables ici.
- **Le formulaire Play Console lui-même** — ces documents préparent les réponses, mais le remplissage se fait dans l'interface Google.
